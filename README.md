Информационная веб-система автоматизации подбора персонала «HR-Подбор». Система предназначена для HR-отделов крупных компаний и кадровых агентств, которые ведут одновременно несколько вакансий, получают много откликов и должны быстро сопровождать кандидата от первого контакта до решения о найме.
Проект является веб-системой: пользователи работают через браузер, а данные о вакансиях, кандидатах, этапах отбора, интервью и результатах хранятся централизованно. Основной акцент системы сделан на автоматизации рутинных действий рекрутера и прозрачности процесса подбора для руководителей.
Границы проекта 
-Система охватывает создание вакансий, прием откликов, ведение базы кандидатов, перемещение кандидатов по этапам отбора, планирование собеседований, уведомления и формирование отчетов.
-Система не заменяет решение руководителя о найме, но помогает собрать информацию, отзывы и историю взаимодействия с кандидатом.
-В первой версии предполагается веб-интерфейс для рекрутеров, руководителей и кандидатов без отдельного мобильного приложения.
